# Контрольная точка №2 — Перегрузка индексаторов

* **Студент:** Диколенко Евгения
* **Дисциплина:** Язык программирования C#
* **Вариант:** 1 (Playlist)

## Описание проекта
Реализация класса `Playlist` с двумя перегруженными индексаторами по теме лекции:
1. `this[int position]` — чтение и запись трека по числовому индексу (с проверкой границ `ArgumentOutOfRangeException`).
2. `this[string title]` — чтение индекса трека по его названию (возвращает `-1`, если не найден).
